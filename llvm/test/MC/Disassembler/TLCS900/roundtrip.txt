# RUN: llvm-mc -triple=tlcs900 -disassemble < %s > %t-disasm.s
# RUN: llvm-mc -triple=tlcs900 -show-encoding %t-disasm.s > %t-reasm.s
# RUN: llvm-mc -triple=tlcs900 -show-encoding %t-reasm.s > %t-reasm2.s
# RUN: diff %t-reasm.s %t-reasm2.s
#
# Disassembler round-trip verification: hex bytes -> disassemble -> reassemble
# -> reassemble again, verifying the reassembled output is stable.
#
# Additionally, each instruction's reassembled encoding is checked against the
# original bytes using FileCheck on the second pass:
# RUN: llvm-mc -triple=tlcs900 -disassemble < %s | \
# RUN:   llvm-mc -triple=tlcs900 -show-encoding | FileCheck %s
#
# This catches encoding/decoding mismatches where the disassembler produces
# valid assembly text that reassembles to different bytes.
#
# === Known round-trip issues (documented, not tested here): ===
# - 32-bit DJNZ: disassembles as "djnz xwa" but reassembles to 16-bit prefix
# - E2 prefix (24-bit direct addr): disassembles as ldl_da (asm-only mnemonic)
