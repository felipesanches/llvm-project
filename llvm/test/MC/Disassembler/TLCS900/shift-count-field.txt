# A shift/rotate count byte of 0 MEANS 16 (the CPU reads `count & 0x0F`, 0
# meaning 16; MAME's DISASSEMBLER prints the raw 0).  Every decode prints 16,
# the only spelling the assembler accepts for that byte.  Rotates print their
# count (ce e9 02 used to print `rrc h`, dropping it); a count of 1 prints the
# one-operand form.  A count byte with its high nibble set is refused -- the
# CPU ignores those bits and no truthful spelling re-encodes them.  MAME
# unidasm's reading quoted.
